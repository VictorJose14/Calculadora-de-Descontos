# 🛒 Calculadora de Descontos

Programa simples desenvolvido em Python para calcular descontos progressivos em compras de acordo com o valor gasto.

---

## 📌 Fórmulas

| Faixa de Valor da Compra | Desconto Aplicado |
| :--- | :--- |
| Abaixo de R$ 200,00 | 5% |
| De R$ 200,00 até R$ 299,99 | 10% |
| R$ 300,00 ou mais | 15% |
